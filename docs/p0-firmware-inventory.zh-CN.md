六份镜像的 XOR 标记检验均显示 `xor-obfuscated`。栈指针、复位向量是对包头后的前 8 字节应用 XOR 0xC8 所得的**启发式候选值**，尚未通过真实 MCU 地址空间、反汇编控制流或实机寄存器读取独立证实。

## 可以得到什么结论

- 六份镜像在假定 Cortex-M 向量表位于包体起点的模型下，都含有形态合理的 SP（`0x200xxxxx`）及 Thumb Reset 地址（最低位为 1）。
- V1 和 V2 包头 0x30 字段不同，吻合当前升级器的两类握手分支，不能将它直接解释成设备菜单的两项版本。
- V2.0.09 的 SP 候选值为 `0x20011308`，相对 SRAM 基址 `0x20000000` 偏移 0x11308（70408 字节）。这**与普通 UV-5RH 开源工程声明的 16 KiB RAM 区域不相容**，因此其内存链接脚本不能直接用于该镜像。该偏移不等于已证实的物理 RAM 容量。
- 六份镜像的 Reset 向量候选均为 `0x0800123D`；这提示相关固件共享类似入口布局，不代表 Pro 一定具有与普通 UV-5RH 相同的引导加载器。

## 尚不能得到什么结论

- 不能确定目标机 MCU 型号、片内 Flash/RAM 真实容量或是否有外部执行存储；
- 不能确定两份不同版本文件是否都适用于同一设备；
- 不能证明 Reset Handler 所在地址已经按原厂链接脚本正确恢复，亦不能证明启动链可通过串口完整恢复；
- 不能证明 RFIC、LCD、GNSS 型号或 GPIO 映射。
